# Rejected two-layer routing experiment

This directory retains the DRC output from the compact two-layer fan-out
attempt. It is **not** a fabrication candidate: KiCad found 591 violations,
including shorts through adjacent plated-through pads.

The active mechanically accurate template and four-layer routing plan are in
[`../four-layer/`](../four-layer/). The report is retained to document why the
two-layer approach was rejected.
